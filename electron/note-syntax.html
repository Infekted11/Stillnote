Spreadsheet formulas

Start a calculationBegin the cell with =
Add / subtract=A1+B1 · =A1-B1
Multiply / divide=A1*B1 · =A1/B1
Powers=A1^2
Group calculations=(A1+B1)*C1
Total several cells=A1+A2+A3
Average several cells=(A1+A2+A3)/3
Percentage of a value=A1*15/100

Spreadsheet calculation rules

Cell addressesA1, B2, AA10 (case-insensitive)
Named columnsUse letter addresses even after renaming
Blank cellsCount as 0 in formulas
Negative numbers=A1*(-2)
Order of operationsParentheses, powers, × / ÷, + / −
Reorder rows or columnsReferences update to follow moved cells
Edit a formulaFocus the cell to edit its source
Supported logicArithmetic only; no IF, AND, OR, comparisons, ranges, or SUM

Spreadsheet errors

Division by zero#DIV/0! — check the divisor
Circular reference#CYCLE! — a formula refers back to itself
Invalid value or formula#VALUE! — check syntax and referenced cells
Text in calculationsReferenced cells must contain numbers or formulas
