01

Start with a vault

Stillnote is a desktop workspace for macOS and Windows. Your vault is a folder on your computer; notes are ordinary Markdown files. You can use notes, local files, canvases, and spreadsheets without setting up an AI account.

  1. Download the latest release for your platform and install it.
  2. Open Stillnote and choose a folder as your vault. An existing folder works too.
  3. Use File in the explorer to create a note or choose another workspace file type. Use Folder to organize files.
  4. Write, link files, and let autosave save your work. Use Settings to configure optional integrations.

Stillnote restores your last vault and file. Back up the vault with your usual backup, version control, or folder-sync tools; Stillnote does not provide its own cloud backup.

02

Files, folders & saving

The explorer displays supported files and folders, including empty folders. Expand or collapse folders, refresh the directory, and use the context menu to rename or delete entries. Drag entries to move them; Shift-click selects multiple entries.

Drop supported files into the explorer to copy them into the vault: up to 100 files per upload, with a 250 MB limit per file. Duplicate names must be resolved before importing. Opening a file uses the appropriate editor or viewer.

Notes and workspace documents save automatically. ⌘ / Ctrl S saves manually. Renaming or moving files inside Stillnote updates vault references, including linked canvas images. External deletions are detected by directory watching and when the app regains focus; deleted files stop rendering and their links become red. Fix the target or restore the file to repair them. External renames are not the same as a rename performed inside the app.

Deleting an entry asks for confirmation. Review that dialog carefully: deletion changes the actual files in your vault. The app’s Home view is a starting point for AI conversations; Escape returns there when no other popup or action needs the key.

Writing & Markdown

Formatting renders as you write. Move the caret onto a formatted line to work with its syntax; move away to see the rendered result. The formatting toolbar gives quick access to common actions. Headings remain plain, without decorative underlines.

05

Links, labels & navigation

Stillnote links use a vault path inside <[… ]> (without the space). Paths start at the vault root, even when the current note is inside a folder. Matching is case-insensitive; use actual filenames and extensions. The link picker, ⌘ / Ctrl K, helps insert file or task links.

ExampleDestination
<[Projects/Plan.md]>A file in the Projects folder.
<[Projects/Plan.md|Open plan]>The same target with a custom label.
<[Projects/Plan.md#next-steps]>A heading or tag anchor.
<[Projects/Plan.md#L24]>Line 24 of the note.
<[#next-steps]>An anchor in the current note.
[[Projects/Plan]]A legacy extensionless note link.

Right-click a rendered link to open it. Use Edit link to reveal and change the raw syntax. The backlinks footer shows notes linking to the current file, with excerpts and line destinations. Keep names unambiguous when selecting destinations.

Red links indicate unresolved vault targets. Stillnote leaves the link text in place so you can repair it, but does not keep rendering a deleted file from a cached copy.

06

Linked previews & !!!

A normal Stillnote link automatically renders supported visual content: images, canvases, spreadsheet tables, audio, video, 3D models, graphs, geometry, and 3D calculators. Graph previews show the graph without the equation list or editing controls. Edit the source file to change the underlying content.

Start an individual target with three consecutive exclamation points to keep it as a link. This affects only that occurrence, preserving navigation, aliases, backlinks, and rename handling. 

<[Garden.png]>
<[!!!Garden.png]>
<[Garden canvas.md]>
<[!!!Budget.md#A5,D8|Open budget]>

Resize image and 3D model previews from their lower-right handle. Images keep their aspect ratio. Model previews allow independent width and height. A missing source stops the preview and marks the reference as broken. Audio and video references are omitted entirely from PDF exports, including links with !!!.

07

Spreadsheets & formulas

A spreadsheet stores text, numbers, and formulas in addressed cells. Enter a formula beginning with =. Addresses use letters for columns and numbers for rows, such as A1 or AA12. Add rows and columns as needed. 

=A1+B1
=(B2-C2)*D2
=A1^2
=-(C3/2)

Supported operations are addition, subtraction, multiplication, division, powers, parentheses, and unary plus/minus. Numeric constants may include decimals or scientific notation. Blank references evaluate to zero. Nonnumeric references produce #VALUE, circular references #CYCLE, and division by zero #DIV/0.

This is an arithmetic formula engine: spreadsheet functions such as SUM and IF, formula ranges, comparisons, and AND/OR logic are not supported. To total three cells, use =A1+A2+A3.

Double-click a column header or press F2 to name it; formulas still use the letter address. Reorder rows or columns by dragging headers or using Alt + arrow keys. References adjust with the move to preserve dependencies. Undo/Redo covers spreadsheet changes. Cell content can also contain Stillnote links.

08

Render a spreadsheet in a note

Linking the spreadsheet’s real Markdown path inserts a table. By default, the table extends from A1 to the furthest populated row and column, including numeric zero and formula cells. Tables use internal row and column lines, stronger separators after the first row and column, and no outside border.

SyntaxRendered cells
<[Budget.md]>Smallest A1 rectangle containing all populated cells.
<[Budget.md#D8]>A1 through D8, inclusive.
<[Budget.md#A5,D8]>A5 through D8, inclusive.
<[!!!Budget.md#A5,D8]>A link only; no table.

Use two complete cell addresses for an offset range. The second must be below and/or to the right of the first. Partial addresses such as #A5,D are invalid. An embed is limited to 50,000 cells; choose a smaller range for large sheets.

09

Canvases

A canvas combines a pen, shapes, lines, text, and images. Choose a tool, then click or drag on the canvas. Use Select to move objects, drag a selection area, resize, rotate, duplicate, or delete selected content. The selection outline rotates with the object. Undo/Redo tracks changes.

The shape and line controls provide their available shapes and endpoints. Choose a color for drawn objects and text. The duplicate icon sits beneath the color selector. Images do not have a color picker and use rounded corners.

Text selection and editing

The first click on an existing text field selects it so it can be dragged. A second click enters text editing. Newly inserted text is ready to edit immediately. Text supports multiple lines and plain-text paste.

Add an image

Click Add image to open a popup with an image link field and the images detected in your vault. Choose a vault image or enter an image URL. New images start on the bottom layer, behind other canvas elements. You can move, resize, rotate, and duplicate them.

Vault image references update when the image or containing folder is renamed or moved inside Stillnote. Deleting the image replaces it with a missing-image indicator; saved image data is not used to hide the broken link. Remote URLs need network access and do not participate in vault rename tracking.

Place the canvas toolbar on the left, right, or bottom in Settings. Link the canvas’s actual .md path from a note to show a preview.

10

Equations, graphs, geometry & 3D

Equations in notes

Wrap math in dollar signs. Stillnote renders supported expressions locally, including powers, subscripts, fractions, roots, integral notation, and Greek symbols. This is a focused math renderer, not a full LaTeX installation. 

$x^2 + y_i$
$\frac{a}{b}$
$\int_0^1 x^2 dx$
$/alpha + /theta$

Right-click an equation for a Desmos preview. Desmos features require an internet connection and your Desmos API key.

Dedicated math files

Create Graph, Geometry, or 3D calculator files to work in the corresponding Desmos tool. Enter expressions or construct geometry using its controls; the tool state saves in the vault file. A key must have access to the chosen tool, including Geometry and 3D where applicable.

Link one of these files into a note to show a graph-only preview without equations or editing controls. Previews use a separate instance and do not overwrite the source. Save a graph in its full editor first if a preview has no saved state to display.

These calculator files differ from imported OBJ/STL/STEP models: calculators plot and construct math; model viewers display existing model files.

12

Audio, video, images & models

Open an image for a dedicated viewer, or link it in a note for a preview. Open audio or video for Stillnote’s custom player, with play/pause, seeking, elapsed time, volume, and mute. Video also has a fullscreen button. Embedded audio uses a compact, padded layout with the filename above its controls.

Change playback speed in the audio or video file’s viewer. Speed is remembered per file and reused by its inline player; the inline render does not show a speed setting.

OBJ, STL, and STEP/STP files open in an interactive 3D viewer. Orbit and zoom to inspect a model. A link can render the same model in a note. This is viewing, not mesh or CAD editing.

PDFs open in a document viewer. AI can read selectable text from supported PDFs, but does not perform OCR on scanned pages. Linked audio/video is playable media, not automatic transcription or audiovisual understanding for AI.

13

Task sheets & task references

A task sheet connects a workspace file to a Google Tasks list. Connect Google Tasks in Settings, then choose an existing list or create one. Task titles, completion, due dates, details, and subtasks can be edited from the sheet. Use Sync to refresh remote changes. Deleting a synced task changes the Google list too.

Stars are local to the task sheet and are preserved on refresh; Google Tasks does not receive them as native stars. Ordinary Markdown checkboxes are separate local note content and do not become Google Tasks automatically.

Link a task to a note 

;;List name/Task name;;

The reference resolves the task by its list and task names, which must be unique. The app adds a stillnote://open backlink to the task’s Details, returning to the line containing the reference in the same vault. Task references update with supported task renames; completed task references are hidden in rendered note content. Use the link picker to avoid mistyping names.

Google Tasks needs a connected account and internet access for synchronization and remote changes. Review changes to shared workflows in the Google Tasks account as well as the local task sheet.

14

Home AI: Ask & Work

Home has two mode buttons immediately above the prompt input. Choose a mode before sending. Enter sends a message; Shift + Enter inserts a new line. AI needs a configured provider, API key, model, and internet connection.

Ask

Ask is read-only. Use it to summarize notes and files, compare sources, explain explicit links, and reason about relationships. For example: “Compare the garden plan with the budget and explain what is missing.” It can inspect vault material as context without changing it.

Work

Work plans and carries out multi-step requests. It can inspect files, create several linked documents, update existing files, analyze tabular data and relationships, and create or link Google Tasks and task lists when that integration is connected. For example: “Read the project notes, ask me about missing deadlines, then create a linked plan and task list.”

Work is instructed to ask follow-up questions when material details are ambiguous. Answer in the conversation so it can continue. It checks file revisions before updates, and has bounded tool steps; a long request may need another turn. Cancel stops further work but does not undo steps already completed. Review the resulting files and tasks.

Recent Home conversations are stored locally, with bounded history passed to the model. AI does not have a general shell or web browser. Table analysis is not an unlimited spreadsheet engine; calculated formula values are not automatically included in raw-data correlation analysis.

15

File AI & linked context

Open the file assistant to ask about the current document or request an edit. PDFs provide read-only extracted text. Supported editable notes, code, and structured documents can receive validated edits.

Edits apply directly. The response provides Undo changes / Redo changes. If the current document changed during the request, the app refuses the stale edit. Invalid structured document output is rejected. Keep reviewing the result; an AI response can still be wrong.

What it receives

Each request includes the current document and bounded context from files directly linked from it, including links in unsaved edits. Linked text and structured files provide excerpts; PDFs provide selectable text. Images, audio, video, and other binary assets contribute metadata rather than automatic vision, transcription, or complete binary contents.

This follows direct outgoing links, not every backlink or every recursively connected file. Context is deduplicated and limited by file count and character budgets; missing or truncated sources are marked. Linked files are read-only sidebar context. Use Home Work for requests that need changes across multiple files.

Enter sends; Shift + Enter adds a line. The selected provider receives the prompt and relevant context when you send a request.

AI providers & API keys

In Settings, choose Groq, OpenAI, or Anthropic, enter that provider’s own API key, and select a supported model. Keys and model preferences are separate for each provider. Use the app’s model discovery rather than assuming that every provider model supports the required structured output.

ProviderSetupUsage
GroqCreate an API key in the Groq console, select Groq in Stillnote, and save the key.The app’s default provider. Free-plan usage is subject to the account’s current model, rate, and daily limits.
OpenAICreate an API key in the OpenAI API platform, configure API billing if required, then save it under OpenAI.API access and billing are separate from a ChatGPT subscription.
AnthropicCreate an API key in the Claude API console, configure API access/billing, and save it under Anthropic.Claude API usage is separate from a consumer Claude subscription.

The app does not switch providers or buy more usage when a quota is exhausted. Groq requests may retry a short rate limit once; a daily or account limit needs time or an account change. Check the provider’s console for current availability, quotas, billing, and errors. No provider’s allowance is guaranteed by Stillnote.

Never paste keys into notes or AI prompts. Keys saved through Settings are encrypted with operating-system protection. AI is optional: local writing and local workspace tools do not require a key.

17

Set up Google Tasks

  1. Open the Google Cloud Console, create a project, and open its dashboard.
  2. In the left sidebar, click Library. Search for Google Tasks API and click Enable.
  3. Return to the project dashboard. Open Credentials, click Create credentials, and select OAuth client ID. Set the application type to Desktop app and create the client.
  4. Copy the Client ID and Client Secret. You’ll need both in Stillnote. Save the secret now while it’s visible.
  5. Under OAuth 2.0 Client IDs, open the client you created. Go to Audience, scroll down to Test users, and add the Gmail address you plan to connect.
  6. In Stillnote, open Settings → Tasks. Paste the Client ID and Client Secret, click Save, then click Connect Google Account.
  7. In your browser, select the Gmail account you added as a test user and confirm access. Stillnote requests access only to your Google Tasks.
  8. Return to Stillnote and open or create a task sheet, then choose a list.

Disconnect through Settings when needed. If authorization fails, check that the API is enabled, the OAuth client is a Desktop app, the right account is permitted by the consent configuration, and your network allows the authorization flow.

Set up Desmos

  1. Obtain your own Desmos API key through Desmos API access.
  2. Save it in Stillnote’s Desmos settings.
  3. Create or open a Graph, Geometry, or 3D calculator file.

Geometry and 3D require corresponding access on the key. If a tool cannot initialize, check the saved key, network connection, and permission for that tool. Saving a file stores its state locally; loading Desmos and its previews still needs the online API.

19

Local meeting transcription

Open a Markdown note and use Meeting Notes to record microphone audio into that note as text. Allow microphone access when requested. Stop the recording to flush remaining audio. Transcription is appended to the original note in chunks rather than being turned into a separate meeting summary.

Whisper Medium runs locally in a worker. The first use downloads the model and can take time and substantial storage; later use reuses the available model cache. Performance depends on your computer. No cloud AI API key is required for this local transcription path.

Wait for the model to be ready, keep the destination note available while recording, and review the recognized text. This is microphone recording, not automatic transcription of every linked audio file.

20

Find, replace & file search

In a note or code editor, press ⌘ / Ctrl F to open the app-styled find panel. It shows match counts and next/previous controls. Enable case sensitivity, whole-word matching, or regular expressions as needed; default search is literal.

Expand replacement to replace one match or all matches. Replacements can be undone. Regex replacement supports capture references such as $1. Enter goes to the next match and Shift + Enter to the previous; Escape closes the panel. F3 / Shift + F3 also navigate matches.

Use ⌘ / Ctrl Shift F for vault file/title search. This is different from the current editor’s text search. ⌘ / Ctrl K opens the link picker.

21

Export a note to PDF

Use Export PDF or ⌘ / Ctrl P from a note. Export renders the whole document, including content beyond the visible editor area, rather than taking a screenshot of the viewport.

The export includes rendered text, equations, highlights, task references, images, canvas previews, spreadsheet ranges, and model snapshots. Graph tools use a screenshot where supported by the API; unavailable graph snapshots receive an explicit fallback message.

Audio and video are omitted completely, including their link labels and links marked with !!!. Other suppressed previews remain links. Missing files cannot be exported as old cached previews. Check the saved PDF before sharing it, especially documents with network images or online graph tools.

22

Appearance, settings & privacy

Choose Light, Sepia, or Dark. Place the notes toolbar on the left, right, bottom, or hide it; the canvas toolbar supports left, right, or bottom. Resize the file explorer and assistant pane to fit your workspace. Settings also holds integration credentials, model selection, keyboard help, syntax help, and the personal dictionary.

Notes and structured content live in your chosen folder. Encrypted credential and dictionary files are stored per vault and hidden from the explorer. Operating-system protection can bind them to the current device/account. If encrypted credentials become unreadable, reset them in Settings and re-enter your keys; this does not delete your notes.

Local-first does not mean every feature stays offline. AI sends relevant context to the chosen AI provider, Google Tasks syncs with Google, Desmos loads online tools, and remote image URLs contact their hosts. The first transcription-model download also requires internet. Back up your own files and avoid publishing credential files with a shared vault.

24

Troubleshooting & getting help

A link is red or a preview disappeared
Check that the real file still exists, use the vault-root path and real .md extension, and refresh the explorer. Remove !!! if you want a preview. Fix broken references after external renames.
A table range fails
Use complete addresses such as #D8 or #A5,D8, with the endpoint below/right of the start. Keep the range under the embed size limit.
AI says unauthorized, unavailable, or rate limited
Check the selected provider, its saved key and supported model, account access/billing, and the provider console’s current limits. Keys are not interchangeable between providers.
A graph will not load
Check the Desmos key, connection, and access to the particular calculator. Open and save the source file before embedding its state.
Audio/video will not play
Check the file exists and its actual codec is supported. Try another encoding; an accepted filename extension alone does not establish codec support.
PDF context is empty
Scans may contain no selectable text. Large documents can be truncated; point AI to a smaller text source or relevant excerpt.

See the Log for changes, GitHub for the project, or Feature requests to draft feedback. The website’s request form prepares an email for you to review and send; it never sends automatically.
